# Animated Rose 🌹

An interactive, blooming 3D/2D parametric rose coded with **HTML, CSS, and JavaScript**.

## Features ✨
- **Parametric Blooming Animation**: Stem grows, leaves branch out, and velvet petals bloom layer-by-layer.
- **Interactive Mouse Tilt**: Parallax response as the mouse moves across the screen.
- **Ambient Floating Particles**: Falling glowing petals and stardust.
- **Romantic Handwriting Font**: Smooth typewriter effect revealing *"I made this code for you ❤️"* upon completion of the blooming animation.
- **Zero Dependencies**: Pure HTML5 Canvas, CSS3, and JavaScript.

## Live Demo / Usage
Simply open `index.html` in any web browser or host on GitHub Pages!
